
## 1. 方案概述
本技术方案针对大模型检索增强生成（RAG）系统的效果评估，将整个评估流程分解为四个核心过程：问题改写评估、意图识别评估、召回重排评估和生成结果评估。通过多维度指标量化评估各环节性能，为系统优化提供可量化的数据支持。

## 3. 评估模块设计
### 3.1 问题改写评估模块
**评估目标**：验证大模型对信控术语改写、上下文补充和问题转换能力

**涉及数据集字段**：

```json
  "conversation_type": "多轮",           // 会话类型：单轮/多轮
  "query": "建国路×大望路路口早高峰东进口左转配时建议。",  // 用户原始请求（必填）
  "history": [                           // 历史对话上下文（多轮必需）
    {"role": "user", "content": "之前的提问..."},
    {"role": "assistant", "content": "之前的回答..."}
  ],

  // ====== 语义理解 ======
  "entities": [                          // 实体标准化（数组结构）
    {"name": "建国路×大望路", "type": "intersection"},
    {"name": "早高峰", "type": "time_period"},
    {"name": "东进口左转", "type": "movement"}
  ],
  "rewritten_query": "查询建国路×大望路路口（CY0142）早高峰时段（07:00-09:00）东进口左转流向的排队长度、流量、饱和度与当前相位绿灯时长，分析排队偏长原因并给出信号配时优化建议", // 改写后请求
```
**评估指标**：

* **改写相似度（RS）**：使用LLM编写提示词进行0-1打分，统计平均分来做总体指标评估

**评估流程**：

1. 输入：原始工程师问题Q
2. 处理：大模型基于问题分类数据，原始问题以及历史数据内容，生成改写后的问题Q'
3. 比对：与人工标注的标准改写Q*进行对比
4. 计算：

```
RS = 使用LLM编写提示词进行0-1打分，最终统计平均分来做评估
```
### 3.2 意图识别评估模块
**评估目标**：验证模型对用户真实意图的识别准确性

**评估指标**：

* **意图识别准确率（IA）**：意图识别用 Precison 和 F1 分数

**评估流程**：

1. 输入：改写后问题Q'
2. 处理：大模型输出意图分类I
3. 比对：与专家标注的标准意图I*对比
4. 计算：

```
IA = 使用自动化评估模块进行Precison和F1分数评估
```
### 3.3 召回重排评估模块
**评估目标**：验证知识库检索的相关性与完整性，当前仅针对重排后最终的结果做了评估，后续可以针对召回覆盖率，重拍准确度等做进一步细化。

**评估指标**：

* **内容召回率（CR）**：是否包含标注中的关键内容

**评估流程**：

1. 输入：原始问题query及改写后Query及意图识别
2. 处理：检索系统返回召回的Top K个相关文档片段{D₁, D₂, ..., Dₖ}
3. 比对：与专家标注的关键内容C*对比
4. 计算：

```
CR = ∑[1 if Dᵢ contains C* else 0] / N（样本总数）
```
### 3.4 生成结果评估模块
**评估目标**：验证最终回答的质量与准确性

**评估指标**：

* **语义相似度（SS）**：生成答案与标注答案的语义相似度

**评估流程**：

1. 输入：召回内容{D₁, D₂, ..., Dₖ}，改写后问题，prompt
2. 处理：大模型生成最终回答A
3. 比对：与专家标注的标准答案A*对比
4. 计算：

```
SS = 使用LLM编写提示词进行0-1打分，最终统计平均分来做评估
```
## 4. 评分体系
|模块|指标|评分范围|
|-|-|-|
|问题改写|改写相似度 (RS)|0-1|
|意图识别|意图识别准确率 (IA)|0-1|
|召回重排|内容召回率 (CR)|0-1|
|生成结果|语义相似度 (SS)|0-1|

## 5. 结论
本技术方案通过四级分解评估体系，实现了对大模型RAG系统效果的全方位量化评估。各模块设计指标均与业务目标高度对齐，具备高度可执行性和可解释性。方案执行后可清晰识别系统瓶颈环节，为模型优化提供明确方向，最终提升RAG系统在信控领域的应用效果。
